# Plotter

The `plotter` MCP server connects to the user's Plotter account. Reviewers mark up
websites, web apps and designs in Plotter; each mark is a **task** tied to a page
element. Use the `apply-feedback` skill when the user asks to apply, fix or work
through Plotter feedback, and `get-feedback` to send a static build for review.

If a Plotter tool says it needs sign-in, tell the user to run `/mcp auth plotter`.
